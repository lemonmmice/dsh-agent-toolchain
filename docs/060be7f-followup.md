1. **预检清理失败也能恢复。** WPR 预检启动、正式内核启动、CLR/JIT/alloc 启动之前，先向租约写入完整资源意图。预检停止抛异常时仍尝试取消；停止未确认时返回 unknown/incomplete，保留可恢复记录。
2. **最终标记写入失败不再阻断 cancel。** 租约中的恢复记录采用临时文件加原子替换；磁盘写入失败不会截断上一份租约。标记仍为 starting、丢失或不可解析时，新实例可以凭同一 attempt 的租约重试清理。成功停掉的会话从记录中移除，已经停止的内核不重复停止。
3. **每次全局收尾前重新检查归属。** 启动与停止共用操作锁；清理附加会话之后、回退取消之前、覆盖恢复记录和释放租约之前均重新校验。异步调用期间出现其他 attempt 时，不发后续全局停止命令、不覆盖其标记。操作锁带进程与随机 token；仅确认旧进程不存在时回收旧锁，活进程或身份未知仍拒绝争抢。
4. **部署自检使用正确目录。** 将 `DSH_PROFILE_DIR`、`DSH_HOME`、`DSH_TOOLCHAIN_REPO_ROOT` 传入诊断 worker。部署戳新增 `sourceRoot`；部署后的模块据此寻找源码，避免用 profile 与自身比较得到假绿。没有独立源码位置时明确报告未比较。可用 `DSH_TOOLCHAIN_REPO_ROOT` 覆盖源码位置。
